# Division Instructions and Flag Analysis

## Example 1: 8-bit Division

| Flag | Status | Explanation |
|---|---|---|
| CF | Undefined | DIV does not define the Carry Flag after execution. |
| PF | Undefined | DIV does not define the Parity Flag after execution. |
| AF | Undefined | DIV does not define the Auxiliary Carry Flag after execution. |
| ZF | Undefined | DIV does not define the Zero Flag after execution. |
| SF | Undefined | DIV does not define the Sign Flag after execution. |
| OF | Undefined | DIV does not define the Overflow Flag after execution. |
| IF | Unchanged | DIV does not modify the Interrupt Enable Flag. |
